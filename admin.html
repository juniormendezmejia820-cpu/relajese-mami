¿Cómo subir una nueva foto de entrega?

  1. Sube la foto a la carpeta entregas en GitHub.
  2. Anota el nombre exacto (ejemplo: cliente_nuevo.jpg).
  3. Abre estudio.html, busca la lista const fotosEntregadas = [...] y añade el nombre entre comillas.

Nota: Por seguridad en GitHub Pages, esta es la forma más estable de que las imágenes no se borren.
